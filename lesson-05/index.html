5.1 5 个时间属性

Time as Data —— 时刻 / 时长 / 间隔 / 集合 / 序
Time as Data — Instant / Duration / Interval / Set / Order

时间不只是「年月日」。在做时序可视化前，必须先把数据拆成 5 个时间属性。不同属性适配不同图表——选错了属性映射，图形就会别扭。Time is more than just "year/month/day". Before visualizing time-series data, you must first decompose the data into 5 time attributes. Different attributes suit different charts — choosing the wrong attribute mapping makes the visualization awkward.

  • 时刻 Instant：Instant:某一瞬间的事件（如地震发生时间、点击时刻）→ 适合用点、圆点、事件标记an event at a single moment (e.g., earthquake time, click timestamp) → suited for points, dots, event markers
  • 时长 Duration：Duration:区间的长度（如通话持续 3 分 20 秒）→ 适合用条形、长度编码the length of an interval (e.g., a call lasts 3 min 20 sec) → suited for bars, length encoding
  • 间隔 Interval：Interval:起止时刻对 [start, end]（如会议 09:00–10:30）→ 适合用区间条、甘特图 (e.g., a meeting 09:00–10:30) → suited for interval bars, Gantt charts
  • 集合 Set：Set:无序的时刻集（如一年内所有感冒发烧的日子）→ 适合用日历热图、点图an unordered collection of instants (e.g., all days with fever in a year) → suited for calendar heatmaps, dot plots
  • 序 Order：Order:带先后关系的序列（如排名随年份变化、剧情线）→ 适合用折线、Storylinea sequence with ordering (e.g., ranking over years, plot lines) → suited for line charts, Storyline
核心提醒：Key Reminder:把原始时间字段映射成哪个属性，决定了你后面用什么 mark + channel。例如同样是「每天访问量」，可当作集合（日历热图）也可当作序（折线图）—— 要看分析目标。Which attribute you map the raw time field to determines what mark + channel you use later. For example, the same "daily visits" can be treated as a Set (calendar heatmap) or an Order (line chart) — depending on the analysis goal. 
// 时刻 Instant：d3.scaleTime + d3.timeMillisecond
const sx = d3.scaleTime()
  .domain([new Date(2024, 0, 1), new Date(2025, 0, 1)])
  .range([40, 720]);

// 时长 Duration：d3.scaleTime 域为 [0, 3600000]（毫秒）
const sDur = d3.scaleTime()
  .domain([0, 3600000]).range([0, 200]);

// 间隔 Interval：d3.timeDays / timeWeeks 生成序列
const days = d3.timeDays(
  new Date(2024, 0, 1),
  new Date(2025, 0, 1)
);

// 集合 Set：日历热图用 %U 周序号 + %w 星期
const fmtWeek = d3.timeFormat('%U');
const fmtDow  = d3.timeFormat('%w');

// 序 Order：d3.scalePoint() + padding 做槽位
const slot = d3.scalePoint()
  .domain(['A','B','C']).range([0, 120]).padding(0.5);
从左到右依次：时刻圆点、时长条、间隔区间、集合散点、序折线。分别对应不同 mark + channel。From left to right: instant dots, duration bar, interval ranges, set scatter, order line. Each corresponds to a different mark + channel.

5.2 法国人名时间序列

法国 INSEE 1900–2018 新生儿姓名流行度
French INSEE 1900–2018 newborn name popularity

经典教学数据集：法国国家统计署（INSEE）发布的 1900–2018 各年份、各名字的新生儿登记数。原始形态是「长表」Classic teaching dataset: newborn registration counts by year and name (1900–2018) published by the French National Institute of Statistics (INSEE). The raw form is a "long table" (year, name, gender, count)，可经 d3.rollup 透视成宽表，直接喂给 d3.line()。, which can be pivoted to a wide table via d3.rollup and fed directly to d3.line().

  • 每条线 = 一个名字，X 轴年份、Y 轴新生儿数Each line = one name, X-axis = year, Y-axis = newborn count
  • 峰值标注：每个名字的「流行顶点」年份Peak annotation: the "peak popularity" year for each name
  • 整体对比：同名的「流行 → 衰退」曲线差异Overall comparison: differences in the "rise → decline" curves of names
D3 关键点：D3 Key Point:时间轴用 d3.scaleTime()，配合 d3.timeYears / d3.timeDecades 生成好看的刻度线。Use d3.scaleTime() for the time axis, paired with d3.timeYears / d3.timeDecades to generate nice tick lines. 
// 1) 读 CSV
d3.csv('../data/french_names_sample.csv', d => ({
  year: +d.year, name: d.name, gender: d.gender, count: +d.count
})).then(raw => {

  // 2) d3.group 按名字分组
  const grouped = d3.groups(raw, d => d.name);

  // 3) 多折线
  const timeExt = d3.extent(raw, d => new Date(d.year, 0, 1));
  const sx = d3.scaleTime().domain(timeExt).range([60, 720]);
  const sy = d3.scaleLinear()
    .domain([0, d3.max(raw, d => d.count) * 1.1])
    .range([340, 40]);

  const line = d3.line()
    .x(d => sx(new Date(d.year, 0, 1)))
    .y(d => sy(d.count))
    .curve(d3.curveMonotoneX);

  const color = d3.scaleOrdinal(d3.schemeTableau10);
  grouped.forEach(([name, rows]) => {
    svg.append('path')
      .datum(rows)
      .attr('d', line)
      .attr('stroke', color(name))
      .attr('fill', 'none');
  });
});
使用 ../data/french_names_sample.csv 数据，展示 MARIE / JEAN / EMMA / LUCAS 等名字的流行趋势。Uses ../data/french_names_sample.csv data, showing popularity trends for names like MARIE / JEAN / EMMA / LUCAS.

5.3 van Wijk 日历热图

Jarke J. van Wijk 2003 —— 7×N 网格日历
Jarke J. van Wijk 2003 — 7×N grid calendar

van Wijk 在 IEEE TVCG 2003 提出的日历视图：把一年的所有日子排成 7 行 × 约 52 列 的网格 —— 行 = 星期几（周日到周六），列 = 第几周。每格的颜色编码当日数值（如日照、温度、PM2.5）。The calendar view proposed by van Wijk in IEEE TVCG 2003: arrange all days of a year into a grid of 7 rows × ~52 columns — rows = day of week (Sunday to Saturday), columns = week number. Each cell's color encodes the day's value (e.g., sunshine, temperature, PM2.5).

  • 周末效应一眼可见（周六周日列可能颜色不同）Weekend effect visible at a glance (Sat/Sun columns may differ in color)
  • 月度模式沿列方向成块Monthly patterns form blocks along columns
  • 年度整体分布比折线更紧凑Annual overall distribution is more compact than a line chart
D3 实现：D3 Implementation:用 d3.timeDays() 生成全年日期，d3.timeFormat('%U') 得周序号（列），d3.timeFormat('%w') 得星期（行），然后逐格填色。Use d3.timeDays() to generate all dates of the year, d3.timeFormat('%U') for week number (column), d3.timeFormat('%w') for weekday (row), then fill each cell with color. 
const year = 2024;
const days = d3.timeDays(
  new Date(year, 0, 1),
  new Date(year + 1, 0, 1)
);

const cellW = 14, cellH = 14, pad = 2;
const fmtWeek = d3.timeFormat('%U');
const fmtDow  = d3.timeFormat('%w');

// 假设我们有每天的数值函数 value(day)
const color = d3.scaleSequential(d3.interpolateViridis)
  .domain([0, 1]);

svg.append('g').attr('transform', 'translate(40,20)')
  .selectAll('rect.day').data(days).enter().append('rect')
  .attr('class', 'day')
  .attr('x', d => +fmtWeek(d) * (cellW + pad))
  .attr('y', d => +fmtDow(d)  * (cellH + pad))
  .attr('width', cellW).attr('height', cellH)
  .attr('rx', 2)
  .attr('fill', d => color(value(d)))
  .append('title')
  .text(d => d3.timeFormat('%Y-%m-%d')(d) + ': ' + value(d).toFixed(2));
行 = 星期几（日到六），列 = 第几周。颜色编码当日模拟数值，鼠标悬停看日期与数值。Rows = day of week (Sun to Sat), columns = week number. Color encodes simulated daily values; hover to see date and value.

5.4 阿基米德螺旋日历

Polar Calendar —— 把一年卷起来
Polar Calendar — roll up a year

日历也可以从二维网格卷进极坐标。把 365 天沿阿基米德螺旋 A calendar can also be rolled from a 2D grid into polar coordinates. Arrange 365 days along an Archimedean spiral r = a + b·θ 排列：从中心往外、同时顺时针旋转。同月聚集在一段弧上，相邻月在螺旋上自然衔接。: outward from the center while rotating clockwise. Same-month days cluster on an arc; adjacent months connect naturally on the spiral.

  • 季节模式（春夏秋冬四段弧）直观可见Seasonal patterns (four arcs for spring/summer/autumn/winter) are intuitively visible
  • 全年数值变化呈环形节奏Annual value changes show a circular rhythm
  • 极坐标让「首尾相连」的周期性更强Polar coordinates strengthen the "end-to-end" periodicity
数学小记：Math Note:阿基米德螺旋的角速度均匀、半径也均匀递增。θ 从 0 绕 2π·k 圈（k≈8 足够铺满画布），b 控制疏密。The Archimedean spiral has uniform angular velocity and uniformly increasing radius. θ goes from 0 around 2π·k turns (k≈8 is enough to fill the canvas), b controls density. 
const W = 760, H = 380;
const cx = W / 2, cy = H / 2;

// 阿基米德螺旋：r = a + b·θ
const a = 0, b = 0.08;
const theta = d3.scaleLinear()
  .domain([0, 365])
  .range([0, 9 * Math.PI]);

// 按月着色
const monthColor = d3.scaleOrdinal(d3.schemeTableau10);

const g = svg.append('g')
  .attr('transform', `translate(${cx},${cy})`);

for (let d = 0; d < 365; d++) {
  const t = theta(d);
  const r = a + b * t;
  const px = r * Math.cos(t);
  const py = r * Math.sin(t);
  const month = new Date(2024, 0, 1 + d).getMonth();
  g.append('circle')
    .attr('cx', px).attr('cy', py)
    .attr('r', 3)
    .attr('fill', monthColor(month));
}
极坐标变换 r = a + b·θ。同月聚集在一段弧上，季节节奏直观可见。Polar transform r = a + b·θ. Same-month days cluster on an arc; seasonal rhythm is intuitively visible.

5.5 Storyline 故事线

Tanahashi & Ma 2012 —— 《侏罗纪公园》案例
Tanahashi & Ma 2012 — Jurassic Park case study

Storyline 是把多角色的「相遇/分离/重聚」编码成一组平行折线的可视化方法。本章以《侏罗纪公园》为例：Grant、Sattler、Hammond、Malcolm、Muldoon 五个角色，在 4 个时间段（开场 / 参观恐龙 / 逃跑 / 结局）的同框关系。Storyline is a visualization method that encodes multiple characters' "meetings/separations/reunions" as a set of parallel lines. This chapter uses Jurassic Park as an example: five characters — Grant, Sattler, Hammond, Malcolm, Muldoon — and their co-occurrence across 4 time periods (opening / dinosaur tour / escape / ending).

  • 每条线 = 一个角色，颜色编码身份Each line = one character, color encodes identity
  • 线条聚拢 = 角色同场（同一 group）Lines converging = characters in the same scene (same group)
  • 线条分开 = 角色分散（不同 group）Lines separating = characters dispersed (different groups)
  • group 内用 Within a group, use d3.scalePoint().padding(0.5) 均匀排 to arrange evenly
D3 实现思路：D3 Implementation:先手动设计每个时段的 group 划分，再用折线生成器 d3.line() 把「(时段, 纵向槽位)」连成角色轨迹。First manually design the group division for each period, then use the line generator d3.line() to connect "(period, vertical slot)" into character trajectories. 
// 5 角色 × 4 时段，手动设计 group 划分
// 时段 0:  全部分散（intro）
// 时段 1:  [Grant, Sattler] [Hammond, Malcolm] [Muldoon]
// 时段 2:  [Grant] [Sattler, Muldoon] [Hammond, Malcolm]
// 时段 3:  [Grant, Sattler, Hammond, Malcolm, Muldoon]

const roles = ['Grant', 'Sattler', 'Hammond', 'Malcolm', 'Muldoon'];
const groupsAt = [
  ['A','B','C','D','E'],           // 时段 0
  ['X','X','Y','Y','Z'],           // 时段 1
  ['P','Q','R','R','Q'],           // 时段 2
  ['S','S','S','S','S'],           // 时段 3
];

// 每个 group 内的纵向槽位
function slotInGroup(groupMembers, role) {
  const idx = groupMembers.indexOf(role);
  const total = groupMembers.length;
  const pos = d3.scalePoint()
    .domain(d3.range(total))
    .range([-60, 60]).padding(0.5);
  return pos(idx);
}

// 计算每个角色在每个时段的 y 偏移
const roleTracks = roles.map(role =>
  groupsAt.map((groups, ti) => {
    const groupMembers = roles.filter((r, i) => groups[i] === groups[roles.indexOf(role)]);
    return {
      t: ti,
      y: groups[roles.indexOf(role)] === groupsAt[ti][roles.indexOf(role)]
         ? slotInGroup(groupMembers, role) : 0
    };
  })
);

const line = d3.line()
  .x(d => sx(d.t))
  .y(d => 200 + d.y)
  .curve(d3.curveMonotoneX);

roleTracks.forEach(track => {
  svg.append('path').datum(track).attr('d', line)
    .attr('stroke', color(roles[roleTracks.indexOf(track)]))
    .attr('fill', 'none').attr('stroke-width', 2);
});
X 轴 = 时间段（开场 → 参观恐龙 → 逃跑 → 结局）。线条聚拢表示角色同场，分开表示分散。X-axis = time period (opening → dinosaur tour → escape → ending). Converging lines mean characters share a scene; separating lines mean they disperse.
