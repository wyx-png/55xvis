3.1 颜色模型

颜色不是单一物理量，而是人对光谱的三刺激值感知Color is not a single physical quantity, but the human perception of tristimulus values of the spectrum

常见颜色模型各有分工：Common color models each have their role:

  • RGB：设备相关、加色混合，不适合插值（中间会漂向灰）RGB: device-dependent, additive mixing; not suitable for interpolation (the middle drifts toward gray)
  • HSL/HSV：色相、饱和度、亮度，但感知仍不均匀HSL/HSV: hue, saturation, lightness; but perception is still non-uniform
  • CIELAB：感知均匀，L 为亮度，a 红绿，b 黄蓝CIELAB: perceptually uniform; L is lightness, a is red-green, b is yellow-blue
  • HCL：基于 CIELAB 的极坐标形式（色相 H、彩度 C、亮度 L），最适合数据可视化插值HCL: polar form based on CIELAB (hue H, chroma C, lightness L); best suited for data visualization interpolation
原则：给数据生成 colormap 时，优先用 HCL 沿色相或彩度方向插值，避免 RGB 直接插值。 Principle: When generating a colormap for data, prefer interpolating along hue or chroma in HCL, and avoid direct RGB interpolation. 
// 从十六进制解析，转换到不同空间
const hex = '#2563eb';
const rgb  = d3.rgb(hex);
const hsl  = d3.hsl(hex);
const lab  = d3.lab(hex);
const hcl  = d3.hcl(hex);

// RGB 插值（不推荐用于数据 colormap）
const lerpRGB = d3.interpolateRgb('#fff', '#2563eb');

// HCL 插值（推荐：感知均匀）
const lerpHCL = d3.interpolateHcl('#fff', '#2563eb');

// 对比：t=0.5 时
lerpRGB(0.5);   // 可能偏灰
lerpHCL(0.5);   // 保持鲜艳

3.2 colormap

把数值域 [a, b] 映射到颜色空间的连续函数A continuous function mapping the value domain [a, b] to color space

colormap 按用途分三大类：Colormaps fall into three categories by use:

  • Sequential 顺序：单方向递增，用于定量无负值（温度、分数、人口密度）Sequential: monotonic increase, used for quantitative non-negative data (temperature, scores, population density)
  • Diverging 发散：有中心点，两端对比（盈亏、Z-score、增长/下降）Diverging: has a center point, contrasting ends (profit/loss, Z-score, growth/decline)
  • Categorical / Qualitative 定类：离散、感知距离均等（分类数据）Categorical / Qualitative: discrete, with equal perceptual distance (categorical data)

另外还有 Cyclic（周期型，如相位、季节）和 Qualitative 变体。选 colormap 的第一步永远是：先看清「数据是什么尺度」。There are also Cyclic (periodic, e.g. phase, seasons) and Qualitative variants. The first step in choosing a colormap is always: first figure out "what scale is the data".

// 1) Sequential 顺序 colormap
const seqScale = d3.scaleSequential(d3.interpolateViridis)
  .domain([0, 100]);

// 自定义 HCL 顺序（蓝→橙）
const seqHCL = d3.scaleSequential(
  t => d3.interpolateHcl('#dbeafe', '#f97316')(t)
).domain([0, 1]);

// 2) Diverging 发散 colormap（红-白-蓝）
const divScale = d3.scaleDiverging(d3.interpolateRdBu)
  .domain([-1, 0, 1]);

// 3) Categorical 分类型
const catScale = d3.scaleOrdinal(d3.schemeTableau10);

// 4) 在 canvas / svg 中取样
seqScale(50);          // → 颜色字符串
d3.interpolateViridis(0.6);  // → '#440154' 之类

3.3 Lab 色域

CIELAB 色域是纺锤而非立方体The CIELAB gamut is a spindle, not a cube

在 L 低（暗）和高（亮）的两端，可表达的彩度 a/b 范围都会收窄。这就是为什么在 HCL 中沿固定彩度插值时，端点要落在色域内——否则会出现「裁剪」或「绕路」。At both the low (dark) and high (light) ends of L, the expressible chroma range a/b narrows. That is why, when interpolating at fixed chroma in HCL, the endpoints must lie inside the gamut — otherwise "clipping" or "detouring" occurs.

可视化技巧：把色域画成 L–C 平面的轮廓，可直观看到「在这个亮度下能用到多鲜艳」。D3 的 d3.interpolateHcl 会自动做色域裁剪，但自己写插值时要留心。 Viz Tip: Drawing the gamut as a contour in the L–C plane makes it intuitive to see "how vivid you can get at this lightness". D3's d3.interpolateHcl does gamut clipping automatically, but be careful when writing your own interpolation. 
// 在给定亮度 L 下，扫描色相 H 找到最大合法彩度 C
function maxChromaAtL(L, steps = 360) {
  let maxC = 0;
  for (let h = 0; h < steps; h++) {
    const c = d3.lab(
      d3.hcl((h / steps) * 360, 0, L)
    ).l ? 0 : 0; // 占位
  }
  // 简化：用 d3.hcl 测试是否在 sRGB 内
  let lo = 0, hi = 230;
  for (let h = 0; h < steps; h++) {
    let c = 0;
    while (c < hi) {
      const col = d3.hcl((h / steps) * 360, c + 1, L);
      const rgb = col.rgb();
      if (rgb.r >= 0 && rgb.r <= 255 &&
          rgb.g >= 0 && rgb.g <= 255 &&
          rgb.b >= 0 && rgb.b <= 255) {
        c++;
      } else break;
    }
    maxC = Math.max(maxC, c);
  }
  return maxC;
}

3.4 5 大色系

按用途归纳的可视化色系族Color system families grouped by use

  • 单色渐变：同一色相的明暗/彩度变化，表达数值大小Monochrome gradient: lightness/chroma variation within one hue, expressing magnitude
  • 双向渐变：从 A 色到白再到 B 色，表达正负对比Diverging gradient: from color A to white to color B, expressing positive/negative contrast
  • 彩虹色：沿色相环走一整圈，慎用——仅当有序且需要最大区分度Rainbow: a full lap around the hue circle; use with caution — only when ordered and maximum discriminability is needed
  • 分类型：离散 N 色，各色之间感知距离应尽量均等Categorical: N discrete colors with perceptual distances as equal as possible
  • 语义型：红绿表意（正负、好坏、涨跌），但必须同时提供形状/亮度编码Semantic: red-green semantics (positive/negative, good/bad, up/down), but must also provide shape/lightness encoding
// 1) 单色渐变（5 级，L 从 90 → 30）
const mono = Array.from({length: 5}, (_, i) =>
  d3.hcl(210, 50, 90 - i * 15).formatHex()
);

// 2) 双向渐变（蓝-白-橙，用 scaleDiverging）
const div5 = d3.scaleDiverging(
  t => d3.interpolateHcl('#2563eb', '#ffffff', '#f97316')(t),
  [-1, 0, 1]
).range([-1, -0.5, 0, 0.5, 1]).map(v => div5(v));

// 3) 彩虹色（沿 H 走一圈）

// 4) 分类型（Wong 8 色即经典一例）

// 5) 语义型（红涨绿跌，但需同时加形状/亮度区分）

3.5 经典科研配色

两套最值得记住的色盲安全离散色板Two colorblind-safe discrete palettes worth memorizing

  • Wong (2011, Nature Methods)：8 色，避开纯红绿冲突，同时在黑白打印下也可区分Wong (2011, Nature Methods): 8 colors, avoiding pure red-green conflict, and also distinguishable in black-and-white printing
  • Paul Tol (2012)：给定性、发散、连续各一套，文档齐全Paul Tol (2012): provides one set each for qualitative, diverging, and sequential; well documented

3.6 对错案例

同样的数据，配色选择如何扭曲感知How color choices distort perception of the same data

同样一张分类散点图，用 jet 看似鲜艳但会引入「假边界」——人眼会把颜色突变处识别为数据边界；换成 Viridis 则边界感弱、感知线性。For the same categorical scatter plot, jet looks vivid but introduces "false boundaries" — the eye interprets abrupt color changes as data boundaries; switching to Viridis weakens the boundary sense and makes perception linear.

错例还包括：用彩虹色表示定序数据、纯红配纯绿表示二元类别但不加形状区分、渐变方向与数据大小不匹配等。Bad cases also include: using rainbow for ordinal data, pure red paired with pure green for binary categories without shape distinction, and gradient direction not matching data magnitude.

// 生成一批二维高斯点
const data = d3.range(200).map(() => ({
  x: d3.randomNormal()(),
  y: d3.randomNormal()(),
  v: d3.randomNormal()()
}));

// ❌ 错：Jet 会引入假边界
const jet = d3.scaleSequential(
  d3.interpolateRgbBasis([
    '#00008f','#0000ff','#00ffff',
    '#00ff00','#ffff00','#ff0000','#7f0000'
  ])
).domain(d3.extent(data, d => d.v));

// ✅ 对：Viridis 感知线性 + CVD 友好
const viridis = d3.scaleSequential(d3.interpolateViridis)
  .domain(d3.extent(data, d => d.v));

3.7 鲜艳+低饱和学生成器

给定 N，一键生成两套离散色板Given N, generate two sets of discrete palettes in one click

一套高彩度（课堂展示/大屏），一套低饱和（论文截图/浅色文档/黑白打印友好）。核心就是固定色相间距、调节 C 和 L：One high-chroma set (classroom display / big screen), one low-saturation set (paper screenshots / light documents / B&W-print friendly). The core is to fix hue spacing and adjust C and L:

切换到演示 Tab：拖动滑块改变 N，实时对比鲜艳 vs 低饱和两套色板的可读性。 Switch to the Demo tab: drag the slider to change N and compare the readability of the vivid vs low-saturation palettes in real time. 
function genPalette(N, vivid) {
  const C = vivid ? 70 : 30;   // 彩度
  const L = vivid ? 55 : 65;   // 亮度（低饱和偏亮，浅底好看）
  return Array.from({length: N}, (_, i) => {
    const h = (i * 360 / N) % 360;
    return d3.hcl(h, C, L).formatHex();
  });
}

// 课堂大屏：鲜艳
genPalette(6, true);
// → ['#ff6bb5','#c87800','#0098ea','#00ab6e','#d1a200','#b366ff']

// 论文截图：低饱和
genPalette(6, false);
// → ['#f5c7dd','#e3c69a','#9fc7e7','#9fd4c0','#e7d59a','#c8aee0']

3.8 CVD 论文图测

Color Vision Deficiency 视角下检验你的配色Test your color scheme from the Color Vision Deficiency perspective

用色盲模拟（Protanopia / Deuteranopia / Tritanopia）对论文图重新渲染，检验不同色板在 CVD 视角下是否仍可分辨。Re-render paper figures with colorblind simulation (Protanopia / Deuteranopia / Tritanopia) to check whether different palettes remain distinguishable under CVD.

  • 红绿色盲（Protanopia / Deuteranopia）最常见，约占男性 8%Red-green colorblindness (Protanopia / Deuteranopia) is the most common, affecting about 8% of males
  • 蓝黄色盲（Tritanopia）较少，约 0.01%Blue-yellow colorblindness (Tritanopia) is rare, about 0.01%
  • Wong / Tol 几乎对所有 CVD 友好；Viridis 本身就是为色盲优化的顺序色板Wong / Tol are friendly to almost all CVD; Viridis itself is a sequential palette optimized for colorblindness
// 简化版 Protanopia 模拟矩阵 (RGB 空间)
// 参考 Machado et al. 2009
const protanopia = [
  [0.567, 0.433, 0.000],
  [0.558, 0.442, 0.000],
  [0.000, 0.242, 0.758]
];

function simulateCVD(hex, matrix) {
  const {r, g, b} = d3.rgb(hex);
  const nr = r * matrix[0][0] + g * matrix[0][1] + b * matrix[0][2];
  const ng = r * matrix[1][0] + g * matrix[1][1] + b * matrix[1][2];
  const nb = r * matrix[2][0] + g * matrix[2][1] + b * matrix[2][2];
  return d3.rgb(nr, ng, nb).formatHex();
}

// 使用：
simulateCVD('#dc2626', protanopia);  // 红色在 Protanopia 下变成...
simulateCVD('#16a34a', protanopia);  // 绿色可能与红撞色

// 更好的方案：用 color.js (https://github.com/LeaVerou/color.js)
// 它内建 CVD 模拟：color.to('protanopia')
